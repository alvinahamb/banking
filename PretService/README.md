Calcul de l’annuité constante (A) :

A=M×t/(1−(1+t)^(−n))
	​
où :
M = montant du prêt (montant)
t = taux périodique = taux / 100 / 12 (si mensuel)
n = duree_mois

Chaque échéance (mensuelle) :

Intérêt = Capital restant × taux périodique
Amortissement = Annuité - Intérêt
Nouveau capital restant = Ancien - Amortissement
